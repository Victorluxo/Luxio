# Luxio v2

Projeto Android preparado para compilação no GitHub Actions.

## Pelo celular
1. Crie um repositório no GitHub chamado `Luxio`.
2. Envie todos os arquivos desta pasta, incluindo a pasta `.github`.
3. Faça commit na branch `main`.
4. Abra **Actions** e selecione **Build Luxio APK**.
5. Toque em **Run workflow** se necessário.
6. Quando terminar, abra a execução concluída.
7. Em **Artifacts**, baixe `Luxio-debug-apk`.
8. Extraia o ZIP e instale `app-debug.apk`.
